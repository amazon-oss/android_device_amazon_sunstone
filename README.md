Device configuration for Amazon Fire Max 11
===========================================

The Amazon Fire Max 11 (codenamed _"sunstone"_) is a tablet from Amazon.

It was announced and released in May 2023.

## Device specifications

| Basic                   | Spec Sheet                                              |
| ----------------------: | :------------------------------------------------------ |
| SoC                     | MediaTek MT8188J                                        |
| CPU                     | Octa-core (2x2.2 GHz Cortex-A78 & 6x2.0 GHz Cortex-A55) |
| GPU                     | Mali-G57 MC3                                            |
| Memory                  | 4 GB, LPDDR4X                                           |
| Storage                 | 64/128 GB, eMMC 5.1                                     |
| Expandable Storage      | microSDXC (dedicated slot)                              |
| Shipped Android Version | 11 (Fire OS 8)                                          |
| Battery                 | Non-removable Li-Po 7500 mAh                            |
| Display                 | 11.0 inches, 1200 x 2000 pixels, IPS LCD                |
| Rear Camera             | 8 MP                                                    |
| Front Camera            | 8 MP                                                    |
